# 2026.10.19 (2026-10-19)

## Changes

- Add `literalizer-group` to place the requested preambles of several generated inputs before their code, emitting identical headers and helper blocks once per group.
  Differing generated helper declarations produce a directive error instead of being combined unsafely.
  ([#586](https://github.com/adamtheturtle/sphinx-literalizer/issues/586))
- Add `:input-root-key:` to `literalizer-call` to render rows nested in JSON, JSON5, YAML, or TOML mappings through the published Literalizer 2026.9.16 API.
- Add support for Python 3.15.
- Run validation workflows for pull requests targeting feature branches so stacked changes receive the normal checks.
